# Code of Conduct

Default Project is intended to be a useful, welcoming open-source project for developers with different backgrounds, experience levels, tools, and opinions.

## Expected behavior

- Be respectful and specific when discussing code, design, or mistakes.
- Critique ideas and changes, not people.
- Assume good intent while still requiring evidence for technical claims.
- Make room for beginners to ask questions without turning reviews into hazing rituals.
- Respect privacy, security boundaries, licenses, and confidential information.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, doxxing, deliberate security harm, spam, or sustained personal attacks are not acceptable.

## Enforcement

Maintainers may edit, hide, reject, lock, or remove contributions and interactions that violate this policy, and may restrict participation when necessary to protect the project or its community.

For sensitive conduct concerns, contact the maintainer through a private GitHub channel when available. Do not publish personal or security-sensitive details merely to prove a point.

## Scope

This policy applies to project repositories, issues, pull requests, reviews, discussions, and other spaces managed for this project.
